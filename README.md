# 园丁日记

一款离线使用的安卓记录应用：在可旋转的人体图上选择部位，把同一事件涉及的多个部位、行为、严重程度、相关人、照片和后续记录放在一起。界面为简体中文。

## 安装与更新

本仓库公开源码，不包含签名密钥。若仓库有正式安装包，请从 GitHub 的 Releases 页面下载。APK 只能安装在安卓设备上，不能直接在 Windows 上打开。

更新已有安装时，需要使用相同签名的 APK **直接覆盖安装**，不要先卸载；不同签名的自行构建包无法覆盖正式版。卸载或清除应用数据会删除本机记录。

## 使用

- 首页人体图支持单指横向旋转、单指纵向滚动页面、双指缩放和平移，并提供正背面按钮、当前视角和左右标识。点击位置可新增事件或查看该部位的记录。头发也可以单独标记。
- 一个事件可标记多个部位；每个标记分别记录行为、0–10 分严重程度，以及一个或多个人名或代称。
- 事件有时间、地点、经过、照片，并可补充带时间和照片的后续。事件和后续均可修改、删除。
- 全部记录按时间由近到远排列，可搜索人名、部位、地点、经过，也可按日期筛选；“按人查找”会按填写的名字或代称归集。
- 相册照片只保存指向原图的引用，请不要删除或移动原图。新拍照片保存在应用自己的本地文件中，能在事件记录里查看，不会自动出现在手机相册中。

## 数据与密码

事件文字数据只存储在当前手机上，使用应用密码派生的密钥加密；密码在本机验证。应用没有账号服务器、云备份、密码找回或自动通知。忘记密码后无法恢复记录。4 位密码便于输入，但保护强度低于 6 位密码。

从相册选择照片时，应用只保存原图的引用；请勿删除或移动原图。使用应用拍照时，照片保存在应用自己的本地文件中，不会自动出现在系统相册。照片文件依靠安卓的应用私有存储保护，没有额外加密。卸载应用或清除数据会删除这些照片。

应用本身不会主动上传记录，安卓系统备份也已关闭。相册原图是否同步到其他地方，取决于手机相册的设置。本仓库不包含用户记录、照片、测试截图、构建产物或签名密钥。

## 源码与构建

网页界面位于 `src/`，原生相册与相机接口位于 `android/app/src/main/java/com/gardendiary/local/`。项目使用 Vite、Three.js 和 Capacitor。

在 Windows 上安装 Node.js 22+、JDK 21 和 Android SDK 后：

```powershell
npm ci
npm run android:sync
cd android
.\gradlew.bat assembleDebug
```

调试安装包位于 `android/app/build/outputs/apk/debug/app-debug.apk`。发布版需要维护者自己的 `signing/garden-diary.jks` 和 `signing/signing.properties`。这两个文件被 Git 忽略，不应上传。没有签名文件时，请构建调试版。
